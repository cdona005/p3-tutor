# Mission: Building and measuring AI agents

## Why
Pass and do well in CSCI 498E/598E, a class on agentic AI. Project 3 is a tutor agent (teach, tutor, quiz, grade) measured with a bench, so understanding how agents work (how their loops run, stop and fail) is what the class and the project test.

## Success looks like
- Explain what ends an agent loop and what can end it badly (tool calls, `stop_reason`, caps).
- Predict how a change to a skill or subagent changes the tutor's behavior before running the bench.
- Read bench results and say what they show about the agent.

## Constraints
- Concise, bullet-point explanations tied to Computer Science (see PREFERENCES.md).
- Bench runs cost subscription usage, so understand a change before running it.

## Out of scope
- Training or fine-tuning models.
- Agent frameworks other than Claude Code and the Claude Agent SDK, unless needed for comparison.
