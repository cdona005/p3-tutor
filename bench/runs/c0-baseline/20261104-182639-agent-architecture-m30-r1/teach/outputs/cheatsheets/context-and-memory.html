Context and memory: one page

Terms

  • Context: all text the model sees for one call (system prompt, tool descriptions, messages, tool results).
  • Context window: the limit on that text, counted in tokens. Tokens also set the price.
  • Session: one conversation; the context ends with it.
  • Notes: text saved outside the window and loaded back later.
  • Retrieval: search a document collection and put the few best chunks in the context.

Rules

  • The model keeps nothing between calls; the program re-sends the history every time.
  • Input tokens for a run = sum over calls of (everything sent that call).
  • Keep tool output small; clear or summarise old results in long runs.
  • Saved notes lose to the official record if they disagree.
