# Language models do not remember earlier conversations on their own

The learner believed a language model automatically remembers what was said in earlier conversations, so the makerspace assistant would recall what each student said last week. This was corrected in the chat: a model only sees the text sent to it in the current request, so any memory across sessions has to be built (saved by the application and put back into the context).
Later lessons on context and memory can build on this; whether the correction landed is still to be checked.

**Evidence:** the learner's message at the start of the session; the correction in the tutor's reply.
