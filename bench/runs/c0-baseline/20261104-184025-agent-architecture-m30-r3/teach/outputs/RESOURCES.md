# Agent architecture Resources

## Knowledge

- [Anthropic Engineering: Effective context engineering for AI agents](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context, context rot, compaction, note-taking, retrieval timing and sub-agents. Use for: anything about what goes in context and how to keep it small.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window and how it grows each turn. Use for: token and cost reasoning; check it for current window sizes.
- [Claude docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  How memory that persists across sessions is built client-side. Use for: designing what the assistant saves.
- [Anthropic: Introducing Contextual Retrieval](https://anthropic.com/news/contextual-retrieval)
  Why chunks lose context and how to fix it. Use for: searching long manuals.
