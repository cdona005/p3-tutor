Context and memory in an agent

From lesson 1.

Terms

  • Context window: the limit on tokens in one model call (system prompt, tool definitions, messages, tool results, and the reply).
  • Context rot: accuracy falls as the context grows.
  • Memory: information stored outside the window and loaded back in.
  • Retrieval: finding relevant stored material and putting it in the context.

Facts to remember

  • The model keeps nothing between calls; the program resends the message list each time.
  • Early tokens are paid for again on every later call, so clear bulky results once used.
  • Nothing survives a session unless saved and loaded again.
  • The model only asks for a search or a file operation; the program runs it.

Where does it go?

Kind of informationPut it in
Small, stays true, matters later (training status)Saved record, loaded at session start
Changes constantly (calendar)Live tool call
Long and shared (manuals)Library; retrieve the top few chunks
Already used (raw results)Clear or drop
