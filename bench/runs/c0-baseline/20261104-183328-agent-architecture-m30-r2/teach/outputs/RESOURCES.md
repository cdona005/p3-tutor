# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Builders' guide to what goes in the context window, trimming, compaction, notes and just-in-time retrieval. Use for: any decision about what the assistant keeps in context.
- [Docs: Context windows (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of how the window is counted and behaves. Use for: current window sizes and token counting (check the page, sizes change).
- [Article: "LLM Powered Autonomous Agents" by Lilian Weng](https://lilianweng.github.io/posts/2023-06-23-agent/)
  Overview of agent components, including short-term and long-term memory with external vector stores. Use for: the vocabulary of agent memory.
