Context and memory

  • Context: all tokens the model gets in one call (system prompt, tools, messages, tool results) plus its response.
  • Context window: the limit on that total. The model keeps nothing between calls; the program re-sends history.
  • Between steps: the program appends to the context. Between sessions: only saved data survives.
  • Context rot: recall declines gradually as the context grows.
