# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context limits, context rot, just-in-time retrieval, compaction and note-taking. Use for: what to keep in context and when to store or retrieve.
- [Docs: Context windows (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How context accumulates each turn, and strategies such as compaction. Use for: how the window fills and what it costs.
- [Docs: Short-term memory (LangChain)](https://docs.langchain.com/oss/python/langchain/short-term-memory)
  Thread-scoped memory with a checkpointer, trimming and summarizing. Use for: coding conversation state.
- [Docs: Long-term memory (LangGraph)](https://docs.langchain.com/oss/python/langgraph/memory)
  Cross-thread memory stores. Use for: saving student data between sessions.
