Context and memory in an agent

  • The model keeps nothing between calls. Its context window (system prompt, tool definitions, messages, tool results, its own output) is everything it sees, and it is limited and billed.
  • Each call resends the whole message list, so input tokens billed = the sum of each call's full input, not the final size.
  • More context is not better: accuracy can fall as it grows (context rot).
