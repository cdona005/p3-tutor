# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a limited resource, context rot, just-in-time retrieval, compaction, note-taking. Use for: what to keep in context and how to handle long tasks.
- [Docs: Context windows (Claude Platform docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window fills per turn, and context rot. Use for: what the window limits and how usage grows.
- [Article: "Contextual Retrieval" (Anthropic)](https://www.anthropic.com/news/contextual-retrieval)
  Chunking, embeddings plus BM25, measured retrieval failure rates (vendor-reported). Use for: designing manual search.
