Context and memory in an agent

Rules

  • The model keeps no state between calls. Your program re-sends the whole message list every call.
  • Window = system prompt + tool definitions + messages + tool results + the reply.
  • Input cost of a run = sum over calls of the whole context at that call. Early results are paid for again on every later call.
  • Bigger context is not better: recall degrades as it grows (context rot).
  • Nothing crosses a session boundary unless your program saves it and loads it back.

Cost pattern

Call k input = call k-1 input + reply k-1 + result k-1. Total = base × calls + the carried-forward replies and results.

Shrinking the context

  • Clear used tool results (lightest touch).
  • Compact: summarize decisions, open items, facts not to re-guess, pointers.
  • Sub-agent: explore in a separate context, return a short summary.

Retrieval

  • Prepare: split by section, prefix each chunk with machine and section, index.
  • Keyword search for exact terms (codes, part numbers); embeddings for meaning; combine them.
  • Wrong answer? Look at what the search returned before editing the prompt.
  • Measure: 20 real questions, count how often the right section is returned.
