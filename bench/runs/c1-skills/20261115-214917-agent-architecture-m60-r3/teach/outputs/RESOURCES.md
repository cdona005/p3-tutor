# Agent Architecture Resources

## Knowledge

- [Anthropic Engineering: "Effective context engineering for AI agents"](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context, attention budget, just-in-time retrieval, compaction, structured note-taking, sub-agents. Use for: any decision about what the assistant keeps in context or saves.
- [Claude docs: "Context windows"](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, what happens at the limit, context rot, compaction and clearing features. Use for: exact behavior and limits; check it for current model sizes rather than trusting third-party pages.
- [Anthropic: "Contextual Retrieval"](https://anthropic.com/research/contextual-retrieval)
  Chunking, embeddings, keyword search and adding context to chunks. Use for: designing and improving manual search.
