Context and memory: one-page reference

From lesson 1. Sources: Anthropic Engineering, context windows docs, memory tool docs.

Terms

  • Context window: all text the model can use for a response, including its own output. Stateless between calls.
  • Token: the unit of size and billing; input and output are billed separately.
  • Context rot: recall and accuracy degrade as tokens grow.
  • Compaction: summarize a long conversation and restart with the summary.
  • Structured note-taking: notes saved outside the window and loaded back later.
  • Retrieval: fetching only the relevant chunks into the context.

Cost of a run

Total input = sum over calls of (everything sent in that call). Each step re-sends the earlier transcript, so tool results are paid for again on every later call.

Retrieval: up front vs just in time

  • Up front: one call, fast; a bad search leaves the model stuck.
  • Just in time: model can re-query; more calls, tokens and time.

Memory tool safety

Validate paths (../), cap file sizes, expire old files, validate sensitive data yourself.
