# Agent architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a limited attention budget, context rot, compaction, note-taking, sub-agents, just-in-time retrieval. Use for: anything about what goes in an agent's context.
- [Building effective agents (Anthropic)](https://www.anthropic.com/research/building-effective-agents)
  The augmented model (retrieval, tools, memory), workflows versus agents. Page notes that some tooling has changed since 2024. Use for: concepts and architecture choices.
- [Lost in the Middle: How Language Models Use Long Contexts (Liu et al.)](https://Huggingface.co/papers/2307.03172)
  Peer-reviewed (TACL 2024) evidence that accuracy drops when relevant text sits mid-context. Use for: justifying retrieval over long-context stuffing.
