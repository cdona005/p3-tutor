Context and memory in an agent

From lesson 1.

PlaceLifetimeUse for
Context windowOne session; resent on every callThe current chat, recent tool results
Notes / memory filesAcross sessions; the program saves and reloadsPer-student facts such as training status
Searchable storePermanent; fetched by a toolLong manuals
  • The model keeps nothing between calls; the program resends the message list.
  • Input read across a request = sum of every call's context, so it grows faster than the final context.
  • Shrink the context: clear old tool results, or compact into a summary.
  • Bigger window = more fits in one call, not more remembered next time.
  • Retrieval: pre-loaded (search first) or just-in-time (agent calls a search tool).
