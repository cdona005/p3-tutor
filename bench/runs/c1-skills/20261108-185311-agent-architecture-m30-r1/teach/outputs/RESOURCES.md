# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, structured note-taking, just-in-time vs pre-loaded retrieval, sub-agents. Use for: context and memory design decisions, and the later multi-agent objective.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, accumulation across turns, compaction and context editing. Use for: exact behaviour of the window and token costs.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/agents-and-tools/tool-use/memory-tool)
  File-based, client-side memory across sessions, with commands and security notes. Use for: designing what the assistant saves between visits.
